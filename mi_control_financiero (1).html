Respaldo de tus datos

Este archivo guarda los datos en el almacenamiento local de este navegador. No se envían a ningún servidor. Si borras los datos del navegador o abres el archivo en otro dispositivo, podrías perder acceso a los registros; descarga un respaldo JSON con regularidad.

Exportar CSV descarga tus movimientos para abrirlos en Excel. El respaldo JSON incluye movimientos, presupuesto, deudas y meta de ahorro.

Consejos de uso

  • Registra los ingresos cuando recibas el dinero.
  • Registra cada gasto con una categoría consistente.
  • Revisa el dashboard al cierre de cada semana y mes.
  • Actualiza el saldo de las deudas después de pagar.
  • Descarga respaldos periódicamente y guárdalos en un lugar seguro.
